## 🚀 Featured Projects

### [ARC Router](/arc) - `/arc`
A modern, lightweight client-side router for Svelte 5 with View Transition API support and advanced animation control.

**Key Features:**
- 🎬 View Transition API integration with GPU acceleration
- 📱 Mobile-optimized transitions
- ⚡ Zero overhead when using native transitions
- 🎨 Built-in transition presets (fade, slide, scale, material)
- 🔄 Direction-aware animations
- 🛡️ Type-safe with full TypeScript support

---

### [WSX WebSocket](/wsx) - `/wsx`
Type-safe WebSocket library with Zod validation for Elysia and browser clients.

**Key Features:**
- 🔒 End-to-end type safety from client to server
- ✅ Runtime validation with Zod schemas
- 🔄 Auto-reconnection with exponential backoff
- 📡 Request/response pattern with Promise-based RPC
- 🚀 CBOR serialization for high performance
- 🔌 First-class Elysia framework integration
